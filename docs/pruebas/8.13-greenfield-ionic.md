# Prueba 8.13 — proyecto nuevo (Ionic) de /init a /release

Proyecto: "Mi Presión" (Ionic React + Capacitor, offline, datos de salud en el dispositivo, sin backend).
Plugin: ai-dd 1.8.1 (los hallazgos se corrigen en 1.9.0). Fecha: 2026-10-02. Respuestas del usuario
simuladas por el agente con la opción recomendada en cada pregunta.

Recorrido: `/init` (greenfield, mobile) → `/specify` → `/clarify` → `/plan` → `/tasks` →
`/analyze` ×4 → `/implement` → `/review` ×2 → `/release` hasta T095 (prueba interna de Google
Play: requiere SDK de Android, firma y dispositivos). El cierre (T096–T098, historial y deuda del
roadmap) se ejecutó en una copia simulada para probar las herramientas.

El origen es un único proyecto (Ionic, español). Según la regla de mantenimiento 4, las reglas del
validador y del hook nuevas tienen casos en `tests/` de otro tipo o idioma (librería Python y CLI
Go en inglés, escenarios Go/Python); las reglas de las skills se formulan sin el stack y usan
Ionic solo como ejemplo.
